@@ rcstatus
rcstatus - Show a combined remote/local comparison

Usage:
  rcstatus REMOTE[:PATH] LOCAL_PATH [OPTIONS...]

What it does:
Print a legend followed by one combined rclone check report. Symbols: =
identical, - local only, + remote only, * different, ! error.

Options:
  --size-only  Compare sizes without checking hashes.
  --include 'PATTERN'  Include matching files.
  --exclude 'PATTERN'  Exclude matching files.
  --max-depth N       Limit traversal depth where applicable.

Examples:
  rcstatus remote1 ./local
  rcstatus remote3:Research ./documents --size-only

Effects:
Does not change local or remote files.

Notes:
Arguments are always REMOTE first, LOCAL_PATH second. Files are compared by
size and available hashes. A nonzero exit code can mean differences or errors.
REMOTE and REMOTE: both mean the remote root. Use REMOTE:PATH for a subfolder;
quote paths containing spaces. Put additional options after the paths.

Help:
  rcstatus -h
  rcstatus --help
  rchelp rcstatus

Help is printed locally before any operation is started.

@@ rcgit
rcgit - Show local-only, remote-only, and changed files

Usage:
  rcgit REMOTE[:PATH] LOCAL_PATH [OPTIONS...]

What it does:
Run three rclone checks and print separate local-only, remote-only, and
different-on-both sections. This does not use Git or synchronize files.

Options:
  --include 'PATTERN'  Include matching files.
  --exclude 'PATTERN'  Exclude matching files.
  --max-depth N       Limit traversal depth where applicable.

Examples:
  rcgit remote1 ./local
  rcgit remote3:Research ./documents --size-only

Effects:
Does not change local or remote files.

Notes:
Three comparisons can take time on large remotes. Errors remain visible and
any failed comparison preserves a nonzero result. Arguments are always REMOTE
first, LOCAL_PATH second. Files are compared by size and available hashes. A
nonzero exit code can mean differences or errors. REMOTE and REMOTE: both mean
the remote root. Use REMOTE:PATH for a subfolder; quote paths containing
spaces. Put additional options after the paths.

Help:
  rcgit -h
  rcgit --help
  rchelp rcgit

Help is printed locally before any operation is started.
